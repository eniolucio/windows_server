# Administração de Servidores Microsoft Windows

Este repositório tem como objetivo armazenar documentações, scripts, procedimentos e anotações relacionadas à administração de servidores **Microsoft Windows**.

## Conteúdo abordado

- Instalação, configuração e gerenciamento de funções (*Roles*) e recursos (*Features*) do Windows Server
- Active Directory Domain Services (AD DS), DNS, DHCP e Políticas de Grupo (GPO)
- Gerenciamento de armazenamento, compartilhamentos de arquivos e permissões NTFS
- Automação e administração via PowerShell
- Implantação, backup, recuperação e boas práticas de segurança
